# 原始实验归档

这里保存原来的 `01_Code/` 和 `02_Data/`，文件内容未改动，供追溯采集协议和处理方法的演变。

当前公开案例统一使用根目录的 **`run_demo.m`**。此目录不加入默认 MATLAB 路径，也不参与案例运行。

`01_Code/` 中的处理版本曾用于交互选区和背景保存，部分版本依赖当前目录里的 MAT 设置文件，且存在函数名与文件名不一致的情况。它们按历史原样保留，不作为本次复现入口。

`Vibration_Dual_Acquirer_v11_5.m` 是原始串口采集界面。硬件、固件和现场采集不在这个离线案例中；默认入口只读取已提交的 CSV。
